# RGD-PERIPH → Console — PERIPH-CONSOLE-01 integration boundary

Source candidate only. The final accepted PERIPH commit and CI evidence are supplied by the extraction owner in the master trackers; never use a floating branch or assume this document implies release acceptance.

- PERIPH owns descriptor/status/action contracts, lifecycle, recovery state and the sole local broker. Console remains a consumer/UI and owns existing IMU ingress, read-only telemetry/WS and offline RI correlation. IMU owns actual acquisition; RI alone owns evidence/ref issuance. No additional producer or resolver.
- First client is **read-only**. Use exact candidate host request/response and public status schemas; validate full shape, scope, version, revision and errors. One request per same-UID private Unix connection, maximum 2048 bytes including newline, 30 s nominal client deadline; no implicit retry of lifecycle operations. Broker unavailability or journal/quarantine errors must display unavailable/unknown/reconciliation-required, not stopped or healthy. Service lifecycle does not prove stream LIVE; stream freshness comes from existing accepted samples.
- Production host broker needs explicit fixed allowlist, private recovery directory, reviewed operator context and no implicit initialization/reset. The former Console-specific installer does not supply this new recovery boundary; do not run it or copy it into PERIPH. Do not mount the broker socket into UID10001 container or weaken SO_PEERCRED, /dev, Docker or privilege restrictions. Transport/auth delegation requires separate review. Use fixtures/offline source compatibility first.
- No browser lifecycle operations before PERIPH-0.3. Registry current Cargo-binary installer cannot install this Python service. Keep existing IMU GET/WS and Pulse K3 independent of PERIPH/RI; missing broker/RI is not a reason to shut down the existing acquisition.
- Cutover plan: pin accepted source/wheel SHA, review installer/owner with IMU instance, test read-only client and fallback against synthetic fixtures, then separate operator-controlled commissioning. Preserve rollback to old consumer without copying or rolling back recovery journal, never start two brokers/readers. Retire old Console host code only after verified ownership and rollback review. No deployment, installation, service start or privilege granted by this handoff.
